# LayoutOverlay

LayoutOverlay is a small Windows utility that shows MacOS-like popup when you switch keyboard layouts.

![Screenshot](Screenshot.png)

Only one instance runs at a time.

## Requirements
- Windows
- .NET 10

## Getting Started
1. Build
   ```
   dotnet build -c Release
   ```

2. Run
   ```
   dotnet run
   ```
